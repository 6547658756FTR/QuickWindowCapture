# 빠른 창 캡처

단축키를 누르는 순간 활성화된 창의 **화면에 보이는 영역**을 PNG로 저장하는 Windows 트레이 앱입니다.

Windows 10과 Windows 11을 지원합니다.

## 다운로드

[GitHub Releases에서 최신 버전 받기](https://github.com/6547658756FTR/QuickWindowCapture/releases/latest)

## 실행

다운로드한 `QuickWindowCapture-v1.6.3.exe`를 실행합니다. 처음 실행하면 설정 창이 열리고, 창을 닫은 뒤에도 알림 영역(트레이)에서 계속 실행됩니다.

- 기본 단축키: `Print Screen`
- 기본 저장 위치: `사진\QuickWindowCapture`
- 트레이 아이콘을 두 번 클릭하면 설정 창이 열립니다.
- 트레이 아이콘을 오른쪽 클릭하면 설정, 저장 폴더, 종료 메뉴가 나옵니다.
- 전역 키보드 후크와 Raw Input을 함께 사용해 입력을 점유하는 게임에서 단축키 감지를 보강합니다.

설정의 **로그인할 때 자동으로 실행하고 트레이에 숨기기**를 선택하면 다음 Windows 로그인부터 설정 창 없이 트레이에서 시작합니다.

관리자 권한으로 실행된 게임이나 프로그램에서 단축키를 감지하지 못하면 설정의 **관리자 권한 호환 모드**를 켭니다. 저장 직후 Windows UAC 확인이 표시되고 앱이 관리자 권한으로 다시 시작됩니다. 이 모드를 켠 상태에서 Windows 자동 실행을 사용하면 로그인할 때도 UAC 확인이 표시됩니다. 한 번만 관리자 권한으로 실행하려면 트레이 메뉴의 **관리자 권한으로 다시 시작**을 사용할 수 있습니다.

## 캡처 방식

- **자동 선택(권장)**: Direct3D GPU 고속 캡처를 먼저 사용하고, 사용할 수 없는 화면에서는 일반 방식으로 자동 전환합니다.
- **일반 모드로 고정**: 키를 누른 순간 보이는 화면을 Windows 기본 화면 복사 방식으로 가져옵니다. 대기 중 GPU 자원을 사용하지 않습니다.
- **고속 게임 모드로 고정**: GPU가 준비한 최신 프레임만 사용합니다. 다른 방식으로 자동 전환하지 않으며, 4K 게임이나 연속 캡처에 적합합니다.

고속 게임 모드는 PNG 압축과 파일 저장을 백그라운드에서 처리합니다.

게임이나 매크로 도구가 캡처 키의 해제 신호를 누락해도 입력이 잠긴 채로 남지 않도록 자동 복구합니다. 전체화면·해상도·HDR·모니터 전환으로 고속 캡처 연결이 끊기면 엔진을 자동으로 다시 시작합니다.

## 효과음

캡처가 성공하면 선택한 효과음이 재생되고 성공 알림 풍선은 표시되지 않습니다. 설정의 **캡처 효과음** 목록에서 **효과음 1~11** 중 하나를 고를 수 있습니다.

- **미리듣기** 버튼 또는 목록 항목 더블 클릭으로 선택한 소리를 확인할 수 있습니다.
- **캡처할 때 효과음 재생**을 해제하면 효과음을 완전히 끌 수 있습니다.
- 기본값에서는 캡처나 미리듣기를 연속으로 실행하면 이전 소리를 먼저 중지하고 선택한 소리를 처음부터 재생합니다.
- **연속 캡처 시 효과음 겹쳐 재생**을 선택하면 빠르게 여러 번 캡처할 때 각 효과음을 독립적으로 겹쳐 재생합니다. 오디오 자원 보호를 위해 동시에 최대 8개까지만 유지합니다.
- 제공된 효과음은 들리지 않는 앞뒤 구간을 제거해 캡처 직후 빠르게 반응합니다.
- 효과음은 실행 파일 안에 포함되어 있어 원본 MP3 파일이나 별도 코덱 설치가 필요 없습니다.
- 효과음 출처: 効果音ラボ

설정 창은 Windows 디스플레이 배율에 맞춰 자동으로 확대되며, 4K 150% 환경에서도 글자와 버튼이 잘리지 않도록 구성되어 있습니다.

저장 실패처럼 확인이 필요한 오류만 알림으로 표시됩니다.

## 다시 빌드하기

PowerShell에서 아래 파일을 실행합니다.

```powershell
.\build.ps1
```

별도 패키지 설치 없이 Windows의 .NET Framework 컴파일러를 사용합니다.

## 참고

- 창이 화면 바깥으로 일부 나가 있으면 현재 화면에 보이는 부분만 저장됩니다.
- DRM으로 보호된 영상, 보안 데스크톱, 일부 하드웨어 가속 화면은 검게 캡처될 수 있습니다.
- 고속 모드에서는 최신 프레임을 유지하기 위해 실행 중 GPU 메모리와 처리 시간을 조금 사용합니다.
- Raw Input은 게임 호환성을 높여 주지만 보안 데스크톱이나 일부 안티치트가 차단하는 입력까지 우회하지는 않습니다.
- 디스플레이 회전 또는 그래픽 드라이버 제한으로 고속 모드를 사용할 수 없으면 자동 모드에서 일반 방식으로 전환됩니다.
- 실행 파일 위치를 옮겼다면 Windows 자동 실행 옵션을 한 번 껐다가 다시 켜 주세요.
